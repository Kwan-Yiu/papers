# PARALLEL

[`MEGATRON.pdf`](MEGATRON.pdf) is the tensor/model-parallel foundation.

The folder is intentionally small: parallelism should be learned through a communication cost model
and current runtime code, not by collecting many training papers. Continue with DeepSeek-V3,
TensorRT-LLM, DeepEP, NCCL documentation, and the distributed stage in the roadmap.
