# PERF

Performance models and system-level inference foundations.

## Reading order

1. [`ROOFLINE.pdf`](ROOFLINE.pdf) — compute vs bandwidth bound;
2. [`TRANSFORMERINFER.pdf`](TRANSFORMERINFER.pdf) — Transformer inference arithmetic;
3. [`DEEPSPEEDINFER.pdf`](DEEPSPEEDINFER.pdf) — kernel/runtime/parallel optimization;
4. [`FLEXGEN.pdf`](FLEXGEN.pdf) — capacity-constrained offloading.

For every paper, write down FLOPs, bytes moved, serial steps, capacity constraint, and the hardware
regime in which the method helps.
